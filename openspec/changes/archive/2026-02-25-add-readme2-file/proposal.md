## 为什么

项目需要一个更加面向中文用户的文档文件，为中文学习者提供完整的中文学习指南。虽然 README1.md 提供了双语内容，但一个纯中文的 README2.md 将更好地服务于中文母语学习者，让他们能够更轻松、更深入地理解项目内容。

## 变更内容

- 在项目根目录添加新的 `README2.md` 文件
- 使用纯中文编写完整的学习指南内容
- 提供更详细的中文技术说明和学习建议
- 包含中文用户特别关注的学习路径和资源

## 能力

### 新增能力
- `readme2-chinese-documentation`: 纯中文文档能力，为中文学习者提供完整的项目介绍、学习目标、技术栈说明和学习路径指导
